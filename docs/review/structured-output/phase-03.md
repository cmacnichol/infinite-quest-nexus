Base: `ac63ac62b443a37be4df85fcc2546dd59c9e560e`.

This patch adds a contracts-leaf `PreparedResponseContract`, finite response-format diagnostic vocabulary, a serializer-facing contract bridge, and an optional trusted `responseContract` on text provider requests. The canonical OpenAI-compatible serializer emits strict `json_schema` payloads, preserving the schema name/body and, for OpenRouter only, `provider.require_parameters` plus the exact verified routing slugs. Native LM Studio rejects contracts before model loading or dispatch. The absent-contract branches retain the historical payload shape and format fallback behavior; contract branches reject stream mismatches, legacy-format-option conflicts, duplicate placement, and missing OpenRouter routes before dispatch. Any contract disables the existing regex fallback, so an HTTP format rejection remains one request.

RED: `tests/unit/provider-request-budget.test.ts` failed before implementation because a strict contract serialized as `{ "type": "json_object" }` rather than `json_schema`.

Transport completion: every post-dispatch prepared-contract failure now becomes a private `PreparedResponseContractError`. Its recovery-only evidence is `{ preparedRequest: { body, payloadHash }, responseId, returnedModel, returnedProviderRoute, partialContent, diagnosticCode }`; `responseId`, `returnedModel`, and `returnedProviderRoute` are nullable observations from headers, HTTP bodies, or any SSE event. The wrapper keeps the original error as its `cause`, so existing `providerTransportErrorDetails` traversal still finds timeout and transport details. Its public message never contains provider body, refusal, or stream-error text.

The deterministic `provider-response-contract-transport` suite exercises both `json_object` and `json_schema` through `callTextProvider`: finite HTTP diagnostics, HTTP and SSE refusals, typed/nested SSE error events, malformed successful JSON, truncated SSE with partial text, response size limits, body-read timeout propagation, preflight no-dispatch, and historical legacy fallback. No structured path redispatches after a failure. A complete normal length-finished response continues through the existing result and validation semantics; partial stream content remains recovery evidence only.
