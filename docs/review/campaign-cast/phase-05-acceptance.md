## Operational limitations

Metadata refresh remains synchronous under the campaign lock. Paging bounds each fetch, not total history-scan work; no production latency claim is made. Context authority and stale-work fences are deterministic; semantic fidelity still depends on the provider. Backfill remains a separate, explicitly requested workflow to implement in phase 06. Deployment rollback should disable context for new jobs while keeping a compatible binary for frozen jobs.
