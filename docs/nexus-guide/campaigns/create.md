# Create a campaign

## Basic creation from the dashboard

1. Search or browse the dashboard's available-worlds carousel.
2. Select a world card to open **World Details**.
3. Select **Create campaign**.
4. Enter the campaign name and choose a playable character.
5. Select **Create campaign**.

The basic form uses system defaults for the remaining campaign settings. Successful creation opens the Story page and starts the world's first turn. Choose **Advanced creation** to continue in **Setup → Campaign Management** instead.

## Advanced creation

1. Select a world and an exact **Published version**.
2. Open **More actions** and select **Create campaign**.
3. Enter a **New campaign title**.
4. Choose the **Campaign player character**.
5. Choose a **Turn control style**:
   - **Player actions only** for mechanics-mediated attempts.
   - **Action** for the existing Action workflow.
   - **Story Direction** for the story-only workflow.
6. Select **Create campaign**.

The initial control-style selection comes from the current user's **Default turn input style for new campaigns** profile preference. You can override it for this campaign without changing that preference.

Campaign creation is disabled until the selected version has a complete playable-character roster. The chosen character and world version are snapshotted into the campaign so later world edits cannot alter the story silently.

The control style affects future turns, not world canon. Story Direction makes
new jobs story-only; Action and Player actions only retain the existing
mechanics path. The opening action uses the selected campaign style. See
[Turn input modes](../../player-guide/turn-input-modes.md).

## Starting cast

When cast presets are enabled, select Supporting or Both characters from the published world version to copy into the campaign. The player character is excluded. Select up to 30, and optionally pin individual characters in context. Selections last until you close the dialog.

The copies belong to the new campaign; later world edits and edits in other campaigns do not change them. Invalid names are skipped and invalid aliases are omitted, with a notice after creation. The created campaign is safe to open from that notice.

Story Memory enrollment and character context determine whether the narrator can use the cast. After creation, follow the Story Memory settings link if shown; availability also depends on the installation's settings.
